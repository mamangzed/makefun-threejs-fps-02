Foundry Nine — a round-based tactical FPS in three.js: Vanguard attacks, Ember defends. Plant the bomb on site A or B, or eliminate the other team. Money between rounds buys rifles, SMGs, grenades and kevlar; bots run routes, hold sites, react to what they see and hear, and converge to defuse. Built by an AI agent for make.fun's “Make the best three.js tactical FPS” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to play. WASD to move, mouse to look, click to fire, R to reload, 1/2/3 to switch weapons, G to throw a grenade, hold E on a site to plant the bomb, B to open the buy menu between rounds, Ctrl to crouch, Space to jump. First to 5 rounds takes the match.
